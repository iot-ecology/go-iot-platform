# 部署文档



## 前置条件
- [x] 安装 Docker
- [x] 安装 Docker Compose 
- [x] 下载本项目 

## 环境搭建步骤

```shell
cd $project_path/docker
sh env-start.sh 
```

## 项目部署步骤

```shell
cd $project_path/docker
sh app-start.sh
```

部署完成后访问: http://localhost:80/ 即可看到项目
